# C.1: profiles

Routes covered: `GET /api/users/{id}`, `PATCH /api/users/me`, and the `user.updated` WebSocket event.
Check: `bash /spec/c/checks/check_c_1.sh`. The rule numbers below match its output.

All routes are under `/api/...`, return JSON, and take `Authorization: Bearer <token>`. The three HTTP nodes listen on `127.0.0.1:8000`, `:8001` and `:8002`. Status codes unless a rule says otherwise: `200` on read/update success, `201` on create, `400` on validation, `401` on missing or invalid auth, `403` on auth-but-forbidden, `404` on unknown id, `409` on conflict, `413` on upload over limit, `423` on writes to an archived channel. Every request must answer within 5 seconds.

## Uses

Registration and login, workspaces with a `#general` channel, and the WebSocket at `ws://127.0.0.1:800x/api/ws?token=<bearer>` (one JSON frame per message). If `/app` is empty, build these first in the smallest form that works.

## Adds

| Function | What it does |
|---|---|
| profile read | returns any user's public profile |
| profile update | updates the caller's own profile fields and persists them |
| profile broadcast | sends `user.updated` to every connected WebSocket on every node |

## Rules

A `UserObj` has `id, username, display_name, timezone, avatar_url, status_text, status_emoji`.

1.1 **Read a profile.** `GET /api/users/{id}` with a valid token returns `200` and `{user}` where `user.id` is the requested id and the body has every field of a `UserObj`.

1.2 **Unknown user.** `GET /api/users/{id}` for an id that does not exist returns `404`.

1.3 **Auth on read.** `GET /api/users/{id}` without a token returns `401`.

1.4 **Update and persist.** `PATCH /api/users/me` with `{"display_name":"New Name","status_text":"away"}` returns `200` and `{user}` with both new values. A later `GET /api/users/{id}` returns the same values, also when sent to another node.

1.5 **Subset update.** `PATCH /api/users/me` with one field leaves every other profile field as it was.

1.6 **Valid timezone.** `PATCH /api/users/me` with `{"timezone":"America/New_York"}` returns `200` and `user.timezone` is `"America/New_York"`.

1.7 **Invalid timezone.** `PATCH /api/users/me` with `{"timezone":"Not/AZone"}` returns `400`. The stored timezone does not change.

1.8 **Field length.** `PATCH /api/users/me` with a `display_name` of 1000 characters returns `400`. The stored display name does not change.

1.9 **Auth on update.** `PATCH /api/users/me` without a token returns `401`.

1.10 **Broadcast.** When a user updates their profile, a WebSocket connected as another user on a different node receives `{"type":"user.updated","user":UserObj}` with the new values in `user`. The frame has no `channel_id` and no `event_id`.
